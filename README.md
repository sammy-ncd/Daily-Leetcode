### Daily Leetcode problems ###
- Do at least one problem a day, can do more if you're feeling it


#### How to ####

1. Upload your file to the corresponding days folder, if it hasnt been created for the day, create it.
2. Name your code file: dayX_[YOUR NAME].py or what ever language you choose.
3. Make sure your code fully submits on leetcode.com
4. Finally once you know your code works, do a runtime and space complexity analysis.
5. Read solutions online to ensure you solved the problem optimally. (I just ask chat gpt and view solutions on leetcode)
6. Use "hints" and "topics" buttons on leetcode if you are stuck.
